# to_human — Progress Presentations

Reports for human review: progress presentations (HTML/PDF), key plots, and
summaries of current findings so a human can see what is happening and redirect
if needed.

## Suggested contents

- Generated progress presentations (`progress-*.html` / `.pdf`)
- The optimization trajectory chart (AUROC over experiments)
- Concise status summaries pointing back to [`../findings.md`](../findings.md)

_Empty at initialization; populated as the outer loop produces meaningful results._

> Note: this directory is gitignored by default (see `../.gitignore`) so generated
> reports do not bloat the repository.
