# Literature

Reference library for the study. Nothing is cited until its details are checked
against a primary source (see the verification record in `literature-review.md`).

## Contents

| File | What it is |
|---|---|
| `literature-review.md` | The 20-paper reference set, organized by the job each paper does in the study. Includes the verification record, the hypothesis-by-hypothesis support summary, and the careful novelty statement. |
| `references.bib` | BibTeX for the 20 cited references (verified 2026-09-14) plus an archived section of 17 earlier-corpus papers (not cited). |
| `survey.md` | Running survey notes: one-paragraph summaries added as new papers are found during the project. |

## Reference-set rule

- **At most 20 cited references** in the locked design.
- **Every reference has a job** (it supports at least one design decision in
  [`../src/experimental-pipeline.md`](../src/experimental-pipeline.md)).
- **Verified before citing**: title, authors, and venue checked against arXiv /
  CVF Open Access / publisher DOI / OpenReview / OpenAlex.

The bracketed numbers `[1]`-`[20]` are the project's citation numbers and are
used consistently in the review, the pipeline document, and `references.bib`.
